# نظام إداري خفيف قابل للتوسع بالإضافات

نظام إدارة خفيف، بدون إطار عمل ثقيل، مبني بـ PHP خام (8.0+) و MySQL، يعمل على أي استضافة
مشتركة عادية دون Docker أو Node.js أو Composer في بيئة الإنتاج، ويدعم العربية وRTL بالكامل.

## المتطلبات

- PHP 8.0 أو أحدث مع امتدادات: `pdo_mysql`, `mbstring`, `json`, `session`.
- قاعدة بيانات MySQL 5.7+ / MariaDB 10.3+.
- خادم ويب Apache مع `mod_rewrite` (ملف `.htaccess` مرفق جاهز).

## التثبيت (بدون Terminal وبدون Composer)

1. ارفع كل الملفات إلى مجلد الاستضافة (المجلد الجذر، أو مجلد فرعي بجانب ووردبريس مثلاً).
2. تأكد أن الصلاحيات تسمح بالكتابة على: المجلد الجذر (لإنشاء `config.php`)، ومجلد `storage/`.
3. افتح الموقع من المتصفح، سيتم تحويلك تلقائياً إلى معالج التثبيت `/install/`.
4. أكمل خطوات المعالج: فحص المتطلبات، بيانات قاعدة البيانات، إنشاء أول شركة وحساب مدير نظام.
5. بعد الانتهاء يُقفل معالج التثبيت تلقائياً، وتُحوَّل لصفحة تسجيل الدخول.

لا حاجة لاستيراد قاعدة بيانات من phpMyAdmin ولا تشغيل أي أوامر — كل شيء يتم من المتصفح.

## البنية

```
index.php            نقطة الدخول الموحدة (Front Controller)
install/              معالج التثبيت (يُقفل تلقائياً بعد النجاح عبر storage/install.lock)
app/
  Core/                نواة النظام: التوجيه، قاعدة البيانات، الجلسات، الصلاحيات، الإضافات...
  Controllers/          متحكمات النواة (شركات، مستخدمون، أدوار، إضافات، إعدادات...)
  Views/                قوالب PHP خام (بدون Blade/Twig)
  routes.php             مسارات النواة
modules/
  tasks/                 إضافة "المهام" كنموذج مرجعي لبناء أي إضافة مستقبلية
    module.json           بيانات الإضافة
    install.php            إنشاء جداول الإضافة
    update.php              ترقية جداول الإضافة عند الحاجة
    uninstall.php            حذف جداول الإضافة عند الإزالة النهائية
    permissions.php           صلاحيات الإضافة (تُزرع تلقائياً)
    routes.php                 مسارات الإضافة (تُحمَّل فقط عند التفعيل)
    nav.php                     روابط القائمة الجانبية
    Widgets/dashboard.php        عناصر الصفحة الرئيسية
    Controllers/ Models/ Views/    ملفات الإضافة الخاصة بها فقط
  phone/                 إضافة "التلفون" (Innocalls SIP/WebRTC): مفتاح API لكل شركة يحدده
                          مدير النظام من /phone/admin، وكل موظف يضيف تحويلته الخاصة من
                          /phone/settings. ودجت اتصال عائم يظهر في كل الصفحات عبر global.php
                          (أول إضافة تستخدم هذا الـ hook). تحتاج رفع ملفي SDK الخاصين بـ
                          Innocalls يدوياً في assets/vendor/innocalls/ (راجع README هناك) -
                          بدونهما تعمل الإضافة عادياً لكن الاتصال الفعلي لا يعمل.
assets/                CSS/JS خفيفة بدون مكتبات خارجية أو CDN
storage/               رفعات الملفات وملف قفل التثبيت (تُنشأ تلقائياً)
```

## نظام الإضافات

- كل إضافة مجلد مستقل تحت `modules/` ولا تختلط ملفاتها بالنواة.
- من صفحة **الإضافات** (لمدير النظام فقط) يمكن: تثبيت / تفعيل / تعطيل / تحديث / إزالة أي إضافة.
- تعطيل إضافة يخفي قوائمها وصفحاتها وعناصر صفحتها الرئيسية ويمنع الوصول لمساراتها فوراً،
  **دون حذف بياناتها** من قاعدة البيانات. إعادة التفعيل تُعيد كل شيء كما كان.
- إزالة إضافة (بعد تعطيلها) تُنفّذ `uninstall.php` الخاص بها لحذف جداولها فقط.

لبناء إضافة جديدة: انسخ بنية مجلد `modules/tasks/` كنقطة بداية.

## الصلاحيات والعضويات

- **مدير النظام**: صلاحيات كاملة على كل الشركات والمستخدمين والإضافات.
- **مدير الشركة**: صلاحيات كاملة داخل شركته فقط؛ يُمنع صراحة من إنشاء/تعديل مدير نظام أو
  رؤية شركات أخرى — هذا القيد مُطبَّق في الخادم (`App\Core\Permission`) وليس فقط بإخفائه بالواجهة.
- **مستخدم عادي**: يعتمد كلياً على الأدوار والصلاحيات الممنوحة له، وكل صلاحية تُفحص من الخادم
  في كل عملية عبر `Permission::check('module.action')`.

## بيانات الاتصال بقاعدة البيانات

تُخزَّن في ملف `config.php` في المجلد الجذر (يُنشأ تلقائياً من معالج التثبيت، غير موجود في
المستودع لأسباب أمنية). راجع `config.sample.php` للاطلاع على الشكل المتوقع.
